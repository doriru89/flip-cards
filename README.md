# 今天吃什么！(Flip Cards App)

A fun, interactive flip card game that helps you decide what to eat today! Inspired by tarot cards with beautiful animations and mystical effects.

## Features

- 🎴 Interactive 3D card flip animations
- 🎨 Beautiful tarot card design with mystical theme
- ✨ Magic circle effect when flipping cards
- 🎲 Random card shuffling using Fisher-Yates algorithm
- 📱 Responsive design for mobile and desktop

## How to Use

1. Enter three food options in the input fields
2. Click "洗牌并生成卡牌" (Shuffle and Generate Cards) to create three cards
3. Click on any card to flip it and reveal your choice
4. Only one card can be flipped per round

## Local Development

Simply open `index.html` in your web browser - no build process required!

## Deployment on Render

This project is configured to deploy as a static site on Render.

### Quick Deploy

1. Push this repository to GitHub
2. Connect your GitHub account to Render
3. Create a new Static Site on Render
4. Select this repository
5. Render will automatically detect the static site configuration from `render.yaml`

The site will be automatically deployed on every push to the main branch.
